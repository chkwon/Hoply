Hoply

iOS HWP / HWPX 문서 뷰어 · iOS HWP / HWPX document viewer

Hoply는 @rhwp/core 위에 만든 개인용 iOS HWP / HWPX 뷰어입니다. 문서는 전부 기기 내에서 처리되며, 어떤 데이터도 외부로 전송하지 않습니다.

Hoply is a personal iOS viewer for HWP / HWPX documents, built on @rhwp/core. All documents are processed on-device; nothing is sent off the phone.
